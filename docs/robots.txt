# redirecting to a domain that no longer answers. What it serves is an older
# copy of documentation whose canonical home is now clickhouse.com/docs/chdb,

# host had to be freed is one of them: chdb-core publishes a PEP 503 index of
# its release wheels at /chdb-core/simple/. A package index is for resolvers,
# not for search engines, so it has nothing to lose here either.
